# Local Avatar Presets

The production local tutor model lives here.

## Current talking avatar

- `nerdy-tutor.glb`: MPFB example avatar from
  [met4citizen/TalkingHead](https://github.com/met4citizen/TalkingHead),
  optimized from 36.82 MB to 2.8 MB with glTF Transform 4.4.1 using Meshopt,
  WebP textures, a 1024 px texture cap, and preserved scene hierarchy
  (`--flatten false --join false`).
- Runtime: `@met4citizen/talkinghead` 1.7.0.
- Source SHA-256:
  `63c645a2a863b9972e9a9c2ed576a1de4c390b8475508e1473e69c87a3ee299c`.
- Optimized SHA-256:
  `7a05c99876f931583a812e9745ee358e52996ede220a5474e5865da28b9e87f3`.
- Model license: CC0.

The previous SVG, CSS, and procedural Three.js presets were removed after the
TalkingHead browser proof passed.
